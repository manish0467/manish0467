### 🧭 What I build

I like tools that are **fast, native and work offline** — a shared **Rust core** powering both a terminal UI and an Android app, a converter that touches 255 formats without uploading a byte, a YouTube client that recommends locally instead of in the cloud.

When I'm not coding, I'm reshaping my **Arch Linux + Hyprland (Omarchy)** desktop — every part of my window manager, bar and workflow is configured in Lua and versioned with GNU Stow.
