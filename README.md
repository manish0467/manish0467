### What I work on

Most of what I build starts from the same annoyance: a tool that needs a network round-trip to do something the machine could already do locally.

That's why there's a Rust core under both my terminal and Android clients, why the file converter handles 255 formats without uploading anything, and why the YouTube client ranks recommendations on-device instead of asking a server.

The rest of my time goes into my Arch + Hyprland desktop. The window manager, bar and widgets are configured in Lua and versioned with GNU Stow, so a fresh install is one command.
